HexPlayer

The ultimate accessible YouTube browser and downloader for NVDA users.

About HexPlayer

HexPlayer is a dedicated desktop application designed specifically from the ground up for visually impaired users utilizing the NVDA screen reader. It allows you to seamlessly browse, view, and download YouTube content without dealing with cluttered web interfaces.

Key Features

  • Comprehensive Downloading: Download individual videos or entire playlists. Supports all available video and audio formats.
  • Personalized YouTube Feed: With secure cookie support, you can view your own personalized YouTube feed directly within the app.
  • Favorites System: Easily save and manage your favorite videos for quick access later.
  • Accessibility First: Engineered exclusively for the NVDA screen reader to ensure perfectly read menus, progress bars, and navigation.
  • Bilingual Support: The interface currently fully supports English and Arabic languages.

Under the Hood

For those interested in the technical details, HexPlayer is built for performance and accessibility using modern tools:

  • OS: Windows 10 and Windows 11(64BIT)
  • Core Engine: Python 3.14
  • GUI Framework: wxPython (Ensuring native Windows accessibility APIs are utilized)
  • Download Engine: yt-dlp
  • YouTube Interactions: Deno JS
