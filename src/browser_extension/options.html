HexPlayer Link Helper

When this is off, use the browser context menu or toolbar button. This extension never changes your browser's HTTP or HTTPS defaults. Turning this on asks the browser for permission to watch link clicks on websites. HexPlayer settings must have safe browser integration enabled for direct Native Messaging launch.

Account & Cookies

Export your active YouTube session cookies directly to HexPlayer for features that require login (such as YouTube Shorts, likes, comments, and watch history).
