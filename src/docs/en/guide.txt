HexPlayer User Guide

About HexPlayer

Program name: {name}
Version: {version}
Developed by: {author}

{name} is the current continuation of Accessible YouTube Downloader Pro. It is a Windows and Linux application built for keyboard and screen-reader users who want to search, browse, play, and download YouTube content without depending on the YouTube web interface.

The program focuses on accessibility first. Most actions are available from menus, buttons, context menus, and keyboard shortcuts. It can play either audio-only or video, download MP4, M4A, and MP3 files, browse playlists and channels, and keep common actions reachable from the keyboard.

Supported environment

HexPlayer is intended for modern 64-bit Windows systems, especially Windows 10 and Windows 11. Older Windows releases and 32-bit systems may not work well because the current Python runtime, yt-dlp, Deno, MPV, and related components no longer target those environments reliably.

Linux environment

Linux support natively targets Fedora 43+ on x86_64 via RPM packages and Ubuntu 24.04+ on amd64/x86_64 via DEB packages, with glibc 2.39 or newer and a graphical desktop session. Both distributions are verified in automated CI and container smoke tests. Generic tarballs are also available for other compatible x86_64 Linux systems. There are no macOS packages, and no ARM release support is promised.

Linux speech announcements use Prism with Speech Dispatcher. Orca provides screen-reader navigation; install and enable it separately if needed. Automated tests do not establish desktop accessibility: focus, control labels, keyboard navigation, and speech still require manual validation with Orca on a real Linux desktop.

Installation on Linux

Check https://github.com/makhlwf/accessible_youtube_downloader_pro/releases for Linux assets. In the download directory, replace VERSION in these commands with the version in the actual downloaded filenames (e.g. 4.8.0). Always verify the checksum before installation.

Single-command unified installer (install.sh)

HexPlayer includes an automated Linux installer script that detects your distribution, installs required packages or source dependencies, and configures URL protocol and browser extension integration:

bash packaging/linux/install.sh
# Or install a specific package:
bash packaging/linux/install.sh --package ./HexPlayer-VERSION-1.x86_64.rpm
# Verify screen reader (Orca) and Speech Dispatcher readiness:
bash packaging/linux/install.sh --check-accessibility

Native RPM package on Fedora / RHEL / CentOS / Rocky / AlmaLinux

Download the HexPlayer-VERSION-1.x86_64.rpm asset and its matching .sha256 file:

sha256sum -c HexPlayer-VERSION-1.x86_64.rpm.sha256
sudo dnf install ./HexPlayer-VERSION-1.x86_64.rpm
hexplayer

DNF resolves all required system dependencies automatically.

Native Debian package on Ubuntu 24.04+ / Debian 12+ / Mint / Pop!_OS

Download the linux-amd64.deb asset and its matching .sha256 file from the same release:

sha256sum -c HexPlayer-VERSION-linux-amd64.deb.sha256
sudo apt install ./HexPlayer-VERSION-linux-amd64.deb
hexplayer

APT installs the required system dependencies. Launch from the application menu or with hexplayer as your normal desktop user, never with sudo.

Tarball on other x86_64 Linux distributions

Download the linux-x86_64.tar.gz asset and its matching .sha256 file. Install the runtime packages for your distribution:

On Fedora:
sudo dnf install gtk3 mpv-libs ffmpeg-free libnotify libsecret webkit2gtk4.1 mesa-libGL mesa-libGLU libSM libXtst speech-dispatcher speech-dispatcher-espeak-ng xdg-utils xclip wl-clipboard

On Ubuntu:
sudo apt update
sudo apt install libc6 libstdc++6 libgtk-3-0t64 libmpv2 ffmpeg libnotify4 libsecret-1-0 libwebkit2gtk-4.1-0 libgl1 libglu1-mesa libsm6 libxtst6 libspeechd2 speech-dispatcher xdg-utils espeak-ng xclip wl-clipboard

Extract and run:
sha256sum -c HexPlayer-VERSION-linux-x86_64.tar.gz.sha256
tar -xzf HexPlayer-VERSION-linux-x86_64.tar.gz
./HexPlayer/HexPlayer

Only extract after successful checksum verification, into a user-writable directory. Launch without sudo. The tarball is not dependency-free: FFmpeg and libmpv are system packages.

Running from source on Linux

Install Git and curl (`sudo dnf install git curl` on Fedora or `sudo apt install git curl` on Ubuntu). Install uv following https://docs.astral.sh/uv/getting-started/installation/ and reopen the terminal if needed so uv is on PATH. Then run:

git clone https://github.com/makhlwf/accessible_youtube_downloader_pro.git
cd accessible_youtube_downloader_pro
sudo bash packaging/linux/install-deps.sh
uv python install 3.14.7
UV_CONCURRENT_BUILDS=1 uv sync --locked
uv run python src/accessible_youtube_downloader_pro.py

The dependency script automatically detects your distribution (Fedora or Ubuntu/Debian) and installs build and runtime libraries via DNF or APT. Python 3.14.7 is pinned in .python-version; wxPython may build from source, requiring time and memory. Run uv and the app as your normal user, not with sudo.

First launch and Linux data locations

Allow an Internet connection for missing runtime downloads on first launch or when a feature first needs them, including yt-dlp, Deno, and YouTube.js dependencies. Linux uses system FFmpeg and libmpv. Managed Deno is installed per-user in $XDG_DATA_HOME/HexPlayer/js_runtime, defaulting to ~/.local/share/HexPlayer/js_runtime.

Settings, database, logs, downloaded tools, and the refreshed browser extension normally live in $XDG_DATA_HOME/HexPlayer, defaulting to ~/.local/share/HexPlayer. A portable.dat marker instead puts app data in the application's data directory. Browser manifests and autostart entries use $XDG_CONFIG_HOME, defaulting to ~/.config. The hexplayer protocol desktop entry is in $XDG_DATA_HOME/applications. Downloads use the HexPlayer folder inside the XDG Downloads directory, or ~/Downloads if none is configured.

Main features

- Search YouTube from inside the app.
- Browse videos, playlists, and channels without opening a browser.
- Open playlist contents and channel tabs inside HexPlayer.
- Play videos as video or as audio-only.
- Use an accessible media player with keyboard shortcuts, volume boost, speed control, chapters, quality selection, equalizer, and audio output device selection.
- Download single videos, playlists, channels, Shorts, live pages where supported, and other supported YouTube links.
- Download as MP4 video, M4A audio, or MP3 audio.
- Choose video quality before downloading video when available.
- Organize playlist and channel downloads into separate folders.
- Detect YouTube links from the clipboard at startup, or continuously when background monitoring is enabled.
- Open supported YouTube links from the browser extension or from external launch links.
- Save local favorites.
- Resume playback from the last saved position.
- Optionally import YouTube cookies automatically from an installed browser or use a cookies file for authenticated features such as home recommendations, watch history, likes, chapters, and some restricted content.
- Check for HexPlayer updates and update external tools such as yt-dlp and Deno.
- Use Arabic or English, with automatic language selection on first run.
- Dedicated YouTube Shorts watching experience with Up/Down arrow navigation, automatic preloading, and seamless continuous looping.
- Use system, light, dark, or high contrast dark themes.

Main window

When HexPlayer starts, press Alt to open the menu bar, or use Tab to move through the main buttons.

Main buttons:

- YouTube Search, Ctrl + F.
- Download from Link, Ctrl + D.
- Play YouTube Link, Ctrl + Y.
- Watch Shorts, Ctrl + Shift + S (requires a configured cookies file).
- Favorites, Ctrl + Shift + F.
- Watch History, Ctrl + H.

If a valid cookies file is configured, the main window may also show home recommendations from YouTube. Use Enter to play a recommendation as audio, Ctrl + Enter to play it as video, and the Load More button to fetch more recommendations.

External tools menu

The External Tools menu contains:

- Show yt-dlp version.
- Check for yt-dlp update.
- Show Deno version.
- Check for Deno update.
- Show YouTube.js (Innertube) version.
- Check for YouTube.js (Innertube) update.
- Refresh YouTube.js (Innertube) cache.
- Open Browser Extension Folder.

yt-dlp is the download and extraction engine. Deno runs JavaScript helpers for several YouTube interaction features, including watch history, home feed, likes, comments, and chapters. YouTube.js (Innertube) is the library used by those helpers to talk to YouTube's internal API. If yt-dlp or Deno is missing, HexPlayer may offer to download it. YouTube.js updates are saved in HexPlayer's user data folder and are used by the Deno service on the next request.

Settings

Open settings from the Main menu or with Alt + S.

General settings:

- Program language: Arabic or English. Restart the app when asked after changing language.
- Download folder: the default download location. The default is the HexPlayer folder inside your Downloads folder; Linux uses the XDG Downloads location when configured.
- Cookies file path: optional Netscape HTTP cookies file. Choose an installed browser from the dropdown list and click "Import from browser" to automatically import YouTube cookies, or use Change to select a file manually, or Delete to clear it.
- Auto-detect links at startup: checks the clipboard once when the program opens.
- Auto-check for updates at startup.
- Auto-load more results: automatically loads more search results and channel items when you reach the end of a supported list.
- Debug messages: for developer troubleshooting.
- Background monitoring: starts HexPlayer at desktop login on Windows or Linux, keeps it available in the system tray, and watches the clipboard for YouTube links. Closing the main window hides the app instead of exiting while this option is enabled.
- Safe browser integration: on Windows and Linux, registers the HexPlayer Native Messaging host and the hexplayer protocol for the browser extension. Linux uses per-user desktop integration and standard Chrome, Chromium, Edge, and Brave configuration paths. It does not take over normal http or https links.
- Theme: System Default, Light, Dark, or High Contrast Dark.

Download settings:

- Direct download format: Video MP4, Audio M4A, or Audio MP3. This controls Direct Download from lists and the player.
- MP3 conversion quality: 96, 128, or 192 kbps.

Player settings:

- Default video quality: 144p through 2160p.
- Default audio quality: Low, Medium, or High.
- Audio output device: system default or another available device.
- Continue watching: resumes a video from the last saved position.
- Repeat track: restarts the current track when it ends.
- Auto-next: plays the next item in the current list when the current item ends.
- Equalizer settings: presets and manual band controls.
- Playback speed step: how much Shift + , or Shift + . changes speed each time.

Repeat and auto-next cannot both stay enabled. Turning one on turns the other off.

Cookies file

Cookies are optional. Without cookies, normal search, playback, and many downloads still work.

You can import cookies automatically by choosing an installed browser (such as Google Chrome, Mozilla Firefox, Microsoft Edge, Brave, Vivaldi, Opera, Chromium, Safari, or LibreWolf) in Settings -> General and clicking "Import from browser". Alternatively, you can specify a Netscape HTTP cookies file manually using Change.

With a valid cookies file, HexPlayer can:

- Show home recommendations in the main window.
- Show YouTube account Watch History.
- Update YouTube watch history while you play videos.
- Fetch YouTube like counts when available.
- Like or dislike videos from the player.
- Post top-level comments on videos from the comments dialog.
- Fetch chapters when available.
- Access videos that require your signed-in YouTube session.

The cookies file should be in Netscape HTTP format. Keep it private because it represents your browser session. If cookie-based downloading fails, HexPlayer retries downloads without cookies when possible.

Channel browsing

Channel pages open inside HexPlayer and include tabs such as Home, Videos, Shorts, Live, Playlists, Community, Channels, and About.

Use the tab control to move between channel sections. Use the Load More button when more items are available. Video items can be played or downloaded. Playlist and channel items open the related view. The About tab shows informational rows and is not playable.

Download from Link

Open the download dialog from the Main menu, the Download from Link button, or Ctrl + D.

The dialog contains:

- Link field. HexPlayer fills this automatically from the clipboard when it detects a supported YouTube link.
- Type: Audio or Video.
- Audio format: M4A or MP3. This appears when Audio is selected.
- Download button.
- Download folder button. This changes the folder for the current download only and does not change your saved default folder.

Supported links include YouTube videos, playlists, channels, handles, user pages, Shorts, live pages, clips, and youtu.be links where the underlying tools can process them.

For playlist and channel downloads, HexPlayer saves files into a dedicated folder. A progress window shows percent, total size, downloaded size, remaining time, and speed when this information is available. Closing the progress window asks whether you want to cancel the download. When a download finishes, HexPlayer can play the downloaded file, show it in File Explorer, or open the download folder.

Play YouTube Link

Open this dialog with Ctrl + Y or from the Main menu. Paste a YouTube video link, or let HexPlayer fill it from the clipboard, then choose Audio or Video. The media player opens with the same controls and download options used for search results.

YouTube Shorts Watching Experience

This feature provides a dedicated, accessible feed for watching YouTube Shorts recommendations inside HexPlayer.

- Opening Shorts: Launch Watch Shorts with Ctrl + Shift + S or from the "Watch Shorts" button on the main window.
- Requirements: Requires a valid Netscape HTTP cookies file configured in Settings so the Deno service can fetch recommended Shorts using the Innertube JS API.
- Video Navigation: Use Up Arrow and Down Arrow to cycle directly between previous and next Shorts.
- Volume Control: Use Shift + Up Arrow and Shift + Down Arrow to increase or decrease playback volume in Shorts mode.
- Preloading & Seamless Looping: HexPlayer preloads upcoming Shorts in the background so switching videos starts instantly without buffering, and automatically loops the current Short natively upon completion.
- Interactive Actions: All player commands—such as Liking (L), Disliking (D), Commenting, and Direct Downloading (Ctrl + D)—operate directly on the currently playing Short.

Automatic link detection

When startup clipboard detection is enabled, HexPlayer checks the clipboard once when it opens.

When background monitoring is enabled, HexPlayer can run in the background, start at desktop login on Windows or Linux, monitor the clipboard, and show a dialog when it finds a supported YouTube link.

The detection dialog offers:

- Download.
- Play for videos.
- Open for playlists.
- Cancel.

Channel links can be downloaded from the detection dialog, but playback is disabled because a channel is a collection, not a single playable item.

Browser integration

HexPlayer includes a browser extension folder. Open it from External Tools, then load it as an unpacked extension in Chrome, Edge, Brave, or another compatible Chromium browser.

To use the extension:

- Enable Safe browser integration in HexPlayer settings.
- Open the browser extension folder from HexPlayer.
- In the browser extensions page, enable Developer mode and choose Load unpacked.
- Select the folder opened by HexPlayer.

The extension can send supported YouTube links to HexPlayer from a right-click context menu or the toolbar button. Its options page includes a 1-click button to export YouTube cookies directly to HexPlayer, diagnostics, a test link, log refresh, log copy, and log clear actions. Optional click interception can be enabled from the extension options page.

On Linux, Native Messaging manifests named com.hexplayer.link_helper.json are registered under $XDG_CONFIG_HOME (default ~/.config) in google-chrome/NativeMessagingHosts, chromium/NativeMessagingHosts, microsoft-edge/NativeMessagingHosts, and BraveSoftware/Brave-Browser/NativeMessagingHosts. A per-user desktop entry registers hexplayer:// through xdg-mime. Automatic registration does not cover every custom profile or Snap/Flatpak browser sandbox. Re-enable integration after moving the source checkout or extracted app, and use the extension folder opened by HexPlayer.

Watch history

Watch History is available from Ctrl + H or from the Main menu. With a valid signed-in cookies file, it lists your YouTube account watch history. Without cookies, or if the account history request fails, it lists videos played locally in HexPlayer.

The history window lists recently watched videos from YouTube. You can play, download, favorite, copy links, open in the browser, and load more history. Enter plays audio, and Ctrl + Enter plays video.

HexPlayer saves local watch history and local resume positions on this computer. Updating your YouTube account watch history requires cookies and Deno.

Troubleshooting

If playback or downloads stop working:

- Use External Tools, Check for yt-dlp update.
- Use External Tools, Check for Deno update if history, likes, chapters, or home feed features fail.
- Use External Tools, Check for YouTube.js (Innertube) update if YouTube interaction features fail after YouTube changes.
- Use External Tools, Refresh YouTube.js (Innertube) cache if Deno reports dependency or cache errors.
- Check that your cookies file still exists and is current, or re-import from your browser in Settings -> General, if authenticated features fail.
- Try the same link without cookies by clearing the cookies path if cookie errors continue.
- Verify the download folder exists and that your user account allows HexPlayer to write to it.
- Use Open Download Folder, Ctrl + P, to confirm where downloads are saved.
- For browser integration, re-enable Safe browser integration, reload the extension, and check the extension options logs.
