About the Program

Program Name: {name}

Version: {version}

Developed by: {author}

Description:

{name} is a modified version of "Accessible YouTube Downloader Pro," originally developed by Suleiman Al-Qasimi. It is an evolution of its predecessor, "Accessible YouTube Downloader," specifically designed to meet the needs of blind Windows users. It provides a comprehensive and accessible experience for YouTube by offering a simple interface compatible with screen readers, filling the gap left by the lack of an official YouTube desktop application for Windows.

Note: The program may not perform well on older versions of Windows (such as Windows 8 and earlier) or 32-bit systems, as modern Python versions have dropped support for those environments.

Key Features:

YouTube Search Support: Search for content directly within the app.

Search Filters: Use filters like "Playlists" to narrow down search results.

In-App Browsing: Browse videos without leaving the program.

Dedicated Accessible Player: A built-in player optimized for accessibility; no web browser required.

Live Stream Support: Play live broadcasts within the app.

Audio/Video Toggle: Play content as an audio track or view the video.

Download Capabilities: Download search results in both audio and video formats.

Play Links: Open and play YouTube links directly through the program.

Link Downloading: Download videos, channels, and playlists via URLs.

Folder Organization: Automatically creates separate folders for playlists and channels during download.

Simultaneous Action: Download and watch clips at the same time.

Clipboard Detection: Automatically detects YouTube links from the clipboard upon startup.

Multilingual Support: Supports several languages for the user interface.

Auto-Language Detection: Automatically detects the system language on the first run.

Update Checker: Built-in feature to check for program updates.

Resume Playback: Option to continue watching from where you last stopped.

Playlist Browsing: Browse the contents of playlists within the application.

Comment Browsing: View comments from within the app.

And various other refinements.

Main Interface

Upon opening the program, a hint will guide you to press the Alt key to view the main menus. You can also navigate using the Tab key to quickly access essential buttons: Search, Download, and Play.

The program contains two main menus:

Main Menu:

Includes options for: YouTube Search, Download YouTube Link, Play YouTube Link, Settings, and Exit.

Shortcuts: Most options have keyboard shortcuts. For example, Ctrl + F opens the Search dialog, and Ctrl + D opens the Download dialog.

YT-DLP Menu:

Dedicated to the tool used for downloading videos:

View YT-DLP Version: Shows the current version of the tool.

Update YT-DLP: Updates the downloading engine (useful if downloading stops working).

About Menu:

User Guide: The manual you are currently reading (can also be accessed via F1).

Check for Updates: Check for and download new versions of the application.

About the Program: A brief message with information about the software.

Contact Me: A sub-menu with various ways to reach the developer.

Program Preferences (Settings)

Access settings via the Main Menu or by pressing Alt + S.
Adjustable Options:

Program Language.

Download Path.

Auto-Detect Links: Automatically checks clipboard on startup.

Auto-Check for Updates: Checks for updates on startup.

Auto-Load More Results: Automatically loads more results when reaching the end of the list. (Can be disabled to save data).

Default Download Format: Choose your preferred format for "Direct Download."

MP3 Conversion Quality.

Enable/Disable Resume Playback.

Auto-Loop: Automatically restarts the clip (Off by default).

Auto-Next: Automatically plays the next video (Off by default).

Cookies File Path: Path to a Netscape HTTP cookies file to be used for viewing and downloading (Optional).

Note: Auto-Loop and Auto-Next cannot be enabled at the same time.

Search & Browsing
Accessing Search:

Method 1: Press Alt, navigate to "YouTube Search," and press Enter.

Method 2: Tab to the "YouTube Search" button on the main interface and press Enter.

Method 3: Use the shortcut Ctrl + F.

Search Filters:

In the search dialog, press Tab to access the filter box:

No Filter: Unrestricted search.

Live: Displays only live broadcasts.

Upload Date: Sorts by the most recent uploads.

View Count: Sorts by the most viewed videos.

Playlist: Limits results to playlists only.

Note: Use arrow keys to navigate filters. Press Enter in the search field to start the search.

Results Window:

Results appear in a list. Use arrow keys to navigate. Press Enter to play the selected video.
Context Menu (Application Key or Shift + F10):

Play: Starts the video.

Play as Audio: Plays without video (Shortcut: Ctrl + Space).

Download: Sub-menu for Video (MP4) or Audio (M4A or MP3). M4A is faster/lighter than MP3.

Direct Download: Downloads using your default setting (Shortcut: Ctrl + D).

Go to Channel: Opens the uploader's channel in your web browser.

Download Channel: Downloads the entire channel based on your direct download settings.

Copy Link: Copies the video URL to the clipboard (Shortcut: Ctrl + L).

Open in Web Browser: Opens the link in your default browser.

Playlist Browsing

When using the "Playlist" filter, the results window will show playlists. Instead of a Play button, there is an Open button to view the videos within that specific playlist. Downloads from this view are automatically organized into a folder named after the playlist.

The Media Player

The player appears when playing a search result or a pasted link.

For Sighted Users: There are on-screen buttons for Previous, Rewind, Play/Pause, Fast Forward, and Next.

For Screen Reader Users: Use the keyboard shortcuts listed below.

Player Menu Bar (Alt):

Download: Same options as the search results window.

Copy Link: Copies the current video URL (Ctrl + L).

Video Description: View the uploader's description (Ctrl + Shift + D).

In the description dialog, you can read text with arrows, press Enter on links, copy text, or export to .txt or .html.

Comments: View comments (Ctrl + Shift + J).

Open in Browser: Opens the video in your web browser (Ctrl + B).

Player Keyboard Shortcuts:

Space: Play/Pause.

Up Arrow: Increase volume (Supports boosting above 100%).

Down Arrow: Decrease volume.

Right Arrow: Fast forward.

Left Arrow: Rewind.

Home: Jump to the beginning.

Numbers 1-9: Jump to percentages of the video (e.g., 5 = 50%).

Ctrl + Right Arrow: Next video.

Ctrl + Left Arrow: Previous video.

Ctrl + Shift + T: Hear current playback time.

Ctrl + Shift + L: Hear total duration.

S: Increase playback speed.

D: Reset playback speed to normal.

F: Decrease playback speed.

Shift + R: Toggle Loop.

N: Toggle Auto-Next.

Enter: Toggle Fullscreen.

Ctrl + D: Direct Download.

Alt + S: Open Settings.

Note 1: The default seek time is 5 seconds. Use - (minus) or = (equals) on the keyboard (or Numpad + / -) to adjust the seek interval between 1 and 10 seconds.
Note 2: You can watch and download simultaneously. Use Alt + Tab to switch between the player and the download progress window.
Note 3: Multimedia keys on your keyboard (Play/Pause/Next/Prev) work even if the application window is not focused.

Download via Link

Access this dialog via the Main Menu, the "Download Link" button, or Ctrl + D.

Link Field: Automatically detects links from the clipboard.

Type: Choose Audio or Video.

Format: Choose M4A or MP3 (for audio).

Download Button: Press Enter to start.

Custom Path: You can temporarily change the download folder for the current session without affecting your permanent settings.

Default Location: Downloads\accessible youtube downloader.

Play via Link

To play a link from an email or external source, press Ctrl + Y. Paste the link, choose Audio or Video mode, and the player will open. All player features and download options remain available.

Favorites

The Favorites window allows quick access to saved videos.

It functions similarly to the Search Results window.

Delete Button: Removes a video from favorites (Shortcut: Delete).

Navigation: When playing from Favorites, the "Next/Previous" shortcuts will cycle through your saved favorite videos.
